# Xurshid & Ruxshona — To‘y taklifnomasi

Mobile-first wedding invitation site with Latin/Cyrillic toggle, gift-unwrapping cover, countdown, map links, card copy, and RSVP.

```bash
npm install
npm run dev
```

Open the local URL on a phone or in Chrome device emulation. Replace parent names and card numbers in `src/i18n.ts` before sharing.
